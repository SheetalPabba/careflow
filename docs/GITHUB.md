# GitHub repository

Canonical repository: https://github.com/SheetalPabba/careflow

CareFlow source was published through the authenticated GitHub connection after the owner created this repository. Source code, migrations, tests and documentation are included; credentials and build outputs are excluded.

## Work locally

```bash
git clone https://github.com/SheetalPabba/careflow.git
cd careflow
npm install
npm run dev:next
```

Follow [SETUP.md](SETUP.md) to configure Supabase and optional notifications. Keep local environment files, service-role keys and real patient data out of Git.
